# AE Car Reel Expressions

After Effects expressions I use when editing luxury car reels for Instagram and short-form video.

By **Adil Imtiaz** · [@by_adilvisuals](https://instagram.com/by_adilvisuals)

## What's inside

| File | Use |
|---|---|
| `expressions.md` | Impact shake, seamless loop, speed-ramp helpers, wheel spin, auto-fade |

## How to use

1. Alt/Option-click the stopwatch on the property (Position, Rotation, Opacity, etc.).
2. Paste the expression.
3. Add the Slider Controls named in the comments to a null or adjustment layer so you can tweak values without editing code.

## Where these come from

Built while editing car reels, including an AI-generated G63 "drop" shot where the camera needed a physical-feeling hit when the wheels landed, and short loops that had to repeat with no visible jump.

## Tips

- Precompose footage before stabilizing, then apply shake on the precomp, not the raw clip.
- Keep shake amplitude small for luxury content. It should feel heavy, not chaotic.
- Turn on motion blur for any layer with a shake expression.
